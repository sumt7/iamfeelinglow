# Contributing

Thanks for thinking of contributing.

## The promise this site keeps

**No signup. No personal data stored. Ever.** Anonymous, cookieless page-view counts via Vercel Analytics and aggregate KV event counts are allowed (no IPs, no cookies, no per-user identifiers). Anything that crosses into individual identification is out. Any contribution must keep that intact.

## Scope

Bug fixes and small features. The site is intentionally minimal — see `CLAUDE.md` for the non-negotiables and the voice. Things that will not get merged:

- Tracking SDKs (Google Analytics, Hotjar, Segment, Sentry, etc.)
- Signup, login, or any account system
- Payment integrations
- Traffic-light colors for severity (red for Dangerous, yellow for Heavy, etc.)
- Marketing / wellness language ("journey", "super", "happy", exclamation marks)
- Build steps, frameworks, or `node_modules`
- Anything that breaks the site for users with JavaScript disabled on the home page

## Process

1. **Open an issue first** using one of the templates so we can talk through scope before code.
2. Fork the repo, branch from `main`.
3. Open a PR. Include a Vercel preview URL if there's a visual change.
4. PR will be reviewed for: keeping `CLAUDE.md` non-negotiables, calm voice, no new dependencies, no tracking SDKs, JS-optional home page intact.

## If you're feeling low right now

Please use the site at https://iamfeelinglow.today instead of opening an issue. The Dangerous tier routes to verified, free crisis hotlines including iCall, Vandrevala, Tele-MANAS, 988, 7 Cups, Befrienders, and Find A Helpline.
